# Valentine's Website 💖

A simple, pixel-themed romantic message website designed for a special someone. 

## Features
- **Pixel Art Aesthetics**: Old-school gaming vibe mixed with romantic colors.
- **Interactive Buttons**: The "Nanti Saja" (Later) button playfully interacts with the user.
- **Secret Messages & Easter Eggs**: Clicking through reveals hidden heartfelt messages.
- **Raining Hearts Animation**: A sweet ending effect with floating emojis.

## Setup & Deployment
This website is a static HTML page, making it incredibly easy to host!

### To view locally:
1. Simply double-click `index.html` to open it in your web browser.

### To host on GitHub Pages:
1. Create a new repository on your GitHub account.
2. Push these files to your repository.
3. Go to your repository's **Settings** > **Pages**.
4. Select the `master` or `main` branch as the source and click **Save**.
5. Your website will be live and ready to share!

## Customization
Feel free to open `index.html` and modify the text to personalize your own message!
